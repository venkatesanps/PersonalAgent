Force 3 · Frequency

The agent is the external trigger

Daily tasks become habits. Quarterly and yearly ones never get the repetition, so they slip.

Log it

One ledger: cadence and lead time

Nudge early

Phone reminder at lead time, not due date

Prep the work

Gather documents, draft the first pass

Track done

Log completion, flag what’s overdue

Example: the yearly Frisco property-tax protest. Ledger it once; the agent nudges you when the season opens and pulls last year’s evidence together.

The agent supplies the memory and the nudge you can’t. A weekly scheduled run checks the ledger and fires reminders on your phone.
